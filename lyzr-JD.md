Our platform enables enterprises to move beyond isolated AI use cases and into reliable, production-grade agentic workflows with strong controls around security, accuracy, and compliance.

About The Role

This role owns how users experience our AI platform.
You’ll build fast, scalable, and reliable frontend systems that sit on top of complex agent workflows. This isn’t a UI-polish role—it’s about architecture, performance, and usability for a product used by developers and enterprises.
If you care about clean frontend systems and want your work to sit at the heart of an AI platform, we want to hear from you.

What You’ll Do

Build and own frontend applications using Next.js (including API routes)
Design clean, responsive interfaces using TailwindCSS / shadcn
Write production-quality TypeScript / JavaScript
Work closely with backend teams to integrate APIs and workflows
Use AI-assisted UI tools (Lovable, V0) where they add real leverage
Choose and evolve libraries/frameworks as the platform grows

Must have

3–5 years building frontend or full-stack products
Strong experience with Next.js, TypeScript, JavaScript
Solid understanding of frontend architecture and performance
Working knowledge of backend systems (Python preferred)
Comfort with ambiguity, speed, and ownership

Why Lyzr

High ownership, low bureaucracy, direct impact
